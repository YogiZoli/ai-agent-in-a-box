# 3x AI Agents In A Box

The "3x AI Agents In A Box" page, moved out of publishing-dreamteam (2026-10-07).
Stateless FastAPI: no database, no Google sign-in, no stored data.

Run: `pip install -r requirements.txt` then `uvicorn app.main:app --reload`.
Tests: `python -m pytest tests -q`.
Variable: `PDT_URL` (default https://dreamteam.commentclient.com), used for links back to PDT.
